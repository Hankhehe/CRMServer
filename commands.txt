================================================================================
CRM Server 常用維護與操作指令清單
================================================================================

【1. 虛擬環境 (Virtual Environment)】
# PowerShell 啟動虛擬環境：
.\env\Scripts\Activate.ps1

# CMD (命令提示字元) 啟動虛擬環境：
.\env\Scripts\activate.bat

# 依 requirements.txt 安裝或同步套件：
pip install -r requirements.txt


【2. 啟動伺服器 (Runserver)】
# 本地端啟動 (預設 http://127.0.0.1:8000)：
python manage.py runserver

# 允許區網連線啟動 (指定 IP 與 Port)：
python manage.py runserver 0.0.0.0:8000


【3. 資料庫遷移與結構變更 (Database Migrations)】
# 檢查模型變更並產生 migration 遷移檔 (所有 App)：
python manage.py makemigrations

# 指定 App 產生遷移檔：
python manage.py makemigrations customers
python manage.py makemigrations probes
python manage.py makemigrations core

# 套用資料庫遷移 (執行 Migration 至作用中資料庫)：
python manage.py migrate

# 檢視目前資料庫各 Migration 的套用狀態：
python manage.py showmigrations

# 資料庫結構與設定安全性檢查：
python manage.py check


【4. 管理員帳號與權限 (Superuser & Auth)】
# 建立新的 Django 超級管理員帳號：
python manage.py createsuperuser

# 修改指定使用者的密碼 (例如 admin)：
python manage.py changepassword admin


【5. 系統測試與偵錯 (Test & Shell)】
# 執行所有單元測試 (含客戶、合約、設備、異動與權限測試)：
python manage.py test

# 進入 Django 互動式命令列 (Shell)：
python manage.py shell


【6. 歷史資料遷移工具 (備用/手動觸發)】
# 若需要手動從 Django/root/db.sqlite3 重新平移資料至新資料庫：
python antigravity_env_tools/migrate_legacy_data.py

# 驗證新資料庫各資料表筆數與正確性：
python antigravity_env_tools/verify_db.py


【7. 系統備份與跨系統還原 (Backup & Restore)】
# 完整打包建立系統備份 (自動包含資料庫與 media/ 附件檔案，儲存於 backups/ 目錄)：
python manage.py backup_system

# 指定特定輸出路徑進行備份：
python manage.py backup_system --output D:\Backups\CRM_Manual_Backup.zip

# 從指定備份檔執行系統還原 (直接完全覆蓋 DB 與附件檔，需輸入 yes 確認)：
python manage.py restore_system backups\CRM_Backup_20261021_081100.zip

# 略過互動確認提示直接執行還原 (適用於腳本自動化)：
python manage.py restore_system backups\CRM_Backup_20261021_081100.zip --yes
